# RouteRAG API Documentation

## Endpoints

- `GET /` - Health check
- `POST /api/upload` - Upload a business document
- `POST /api/query` - Query with RAG (Retrieval-Augmented Generation)

## Usage
- Upload documents via `/api/upload`
- Ask questions via `/api/query`

## Frontend Pages
- `/` - Home
- `/upload` - Upload page
- `/chat` - Chat/QA page
- `/analytics` - Analytics dashboard
